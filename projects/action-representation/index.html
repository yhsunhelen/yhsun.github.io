From experimental contrasts to general principles

What the moving blade reveals about learning.

Reuse physical regularities

Position changes should not force relearning.

Body-relative inputs reduce redundant variation when the same interaction moves to a new world pose. Surface-relative inputs help across equivalent contact locations.

Keep predictive information

Geometry alone does not determine every outcome.

Omitting peel thickness creates indistinguishable inputs with different consequences. This limitation concerns the combined state–action information, not the action vector alone.

Verify learned consistency

A correct coordinate transform does not guarantee a correct prediction.

With the actual cutting interaction held fixed, perturbing the estimated local coordinate origin degrades the learned predictor. The effect is distinct from true execution error.

A useful action representation makes equivalent physics reusable without hiding the physical differences that matter.
