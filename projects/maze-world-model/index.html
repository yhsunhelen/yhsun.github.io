Yuhang Sun

When does past experience help an agent navigate a changing world?

A dynamic maze separates learning how spatial structure changes from learning what actions do. Shared spatial memory improves prediction across encounters and transfers to a transition unseen during training.

Overview

An agent can successfully replan around a blocked gate on every visit without becoming better at predicting the next blockage. This study asks whether repeated physical experience can yield reusable knowledge about environmental change.

In a simulated circular maze, Spatial Change Memory (SCM) pools evidence about relations among spatial transitions across episodes. Observing one change can then update a downstream gate belief before that gate becomes directly visible, allowing the agent to revise its route earlier.

The evaluation includes a withheld spatial transition, a zero-information control, and matched interventions that test whether improved predictions lead to appropriately different actions.
