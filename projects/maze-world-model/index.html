TL;DR

Repeated physical experience can support more than reactive replanning. By learning relations among spatial changes across episodes, an agent can transfer that structure to a withheld transition and act before the change becomes directly visible.

Abstract

Agents often adapt successfully to a changed environment while retaining little that helps with the next change. This work asks whether a compact memory of past physical encounters can support transferable spatial prediction. We study the question in a controlled circular maze whose gates change across episodes.

Spatial Change Memory (SCM) accumulates statistical relations between transitions, then uses an observed cue to revise belief about a different, not-yet-visible transition. A matched reactive policy updates only after local observation. The resulting difference is behavioral and measurable: SCM abandons an obsolete route earlier and completes the maze sooner in the representative telemetry rerun.

Method

From local adaptation to transferable structure

The design separates remembering a route from learning a relation that can be applied somewhere new.

Spatial Change Memory

Predict from accumulated relations

Evidence gathered across episodes updates a shared model of how spatial transitions co-vary. A cue at one gate can therefore revise belief about a downstream gate before it enters the observation radius.

Reactive baseline

Revise after local observation

The baseline shares the maze, controller, and current observations, but keeps pursuing its existing target until direct sensory evidence triggers a local map update.

Evaluation design

What the experiment isolates

Withheld transition
Tests whether learned structure transfers beyond a response memorized at the test location.
Zero-information control
Checks that route changes depend on an informative cue rather than an automatic update.
Matched intervention
Holds the world, seed, physics, and low-level controller fixed while changing the downstream prediction.
